# Burn Draft — Frontend API Specification

A burn draft is a rotating (rotisserie) draft. On your turn you **draft N cards**
and **burn M cards** from the pack you are holding, then the remaining pack is
passed to the next player. When all packs are exhausted the next "generation"
of packs is dealt and the passing direction flips, exactly like a classic draft.
The game completes when every dealt pack has been consumed.

## Conventions

- All bodies are `application/json`.
- **Player identity is the `X-Player-Token` header** on every player-scoped
  endpoint. Tokens are assigned when the game is created (or when started via a
  lobby, the lobby player token becomes the game token). Never put a token in a
  URL or request body.
- The game ID is generated by the backend on creation; the client never sends it.
- Field order in responses is stable, but clients should bind by **name**.
- `playerToken` is never included in any response.
- Timestamps are ISO-8601 UTC instants (`2026-11-07T04:31:24.779Z`).
- Base URL is the same host/port as the rest of the API (e.g.
  `https://api.example.com`).

## Enums

| Enum | Values (as serialized in responses) | Notes |
|---|---|---|
| `GameState` | `GAME_STARTED`, `GAME_MERGED`, `GAME_COMPLETE` | burn drafts use `GAME_STARTED` and `GAME_COMPLETE`; `GAME_MERGED` is pyramid-only |
| `DraftDirection` | `ASCENDING`, `DESCENDING` | passing direction for the current generation |
| `BurnRemainderPolicy` | `BURN_EXTRAS`, `DRAFT_EXTRAS` | how a non-divisible final pass is handled |

Request values for `remainderPolicy` accept `burn_extras` / `draft_extras`
(case-insensitive) as well as the uppercase names.

```json

  "cardsInPack": [ /* Card... */ ],
  "originalCardsInPack": 6,

}
```

`doubleDraftedFlag` is a pyramid-draft feature and is always `false` here.
The order of `cardsInPack` is not meaningful — treat it as a set.

## Endpoints

### 1. Create and start a game

`POST /burn-game`

Creates the game, downloads the cube, deals the packs and starts the draft.
The backend generates the `gameID`; the first player on the clock is whoever
received an opening pack (every player starts with one).

**Request**

```json
{
  "cubeID": "my-cube-id",
  "players": [
    { "name": "Alice", "accountID": "acct-1", "playerToken": "tok-alice" },
    { "name": "Bob",   "accountID": "acct-2", "playerToken": "tok-bob" },
    { "name": "Carol", "accountID": "acct-3", "playerToken": "tok-carol" },
    { "name": "Dave",  "accountID": "acct-4", "playerToken": "tok-dave" }
  ],
  "numberOfPacks": 8,
  "cardsPerPack": 6,
  "packsPerPlayer": 2,
  "cardsDraftedPerPack": 1,
  "cardsBurnedPerPack": 1,
  "remainderPolicy": "burn_extras"
}
```

| Field | Type | Rules |
|---|---|---|
| `cubeID` | string | 1–64 chars, `[A-Za-z0-9._-]+` |
| `players` | array | 2–12 entries |
| `players[].name` | string | required, ≤50 chars, no control characters |
| `players[].accountID` | string? | ≤100 chars, optional |
| `players[].playerToken` | string? | ≤64 chars; generated if omitted |
| `numberOfPacks` | int | must equal `players.length × packsPerPlayer` |
| `cardsPerPack` | int | 1–25 |
| `packsPerPlayer` | int | 1–30 |
| `cardsDraftedPerPack` | int | ≥1 |
| `cardsBurnedPerPack` | int | ≥0 |
| `remainderPolicy` | enum | `burn_extras` (default in lobby) or `draft_extras` |

Additional validation:

- `cardsDraftedPerPack + cardsBurnedPerPack ≤ cardsPerPack`
- `players × packsPerPlayer × cardsPerPack ≤ cube size` (otherwise `400`)

**Response `200 OK`** — `BurnGameInfo`

```json
{
  "gameID": "8b1f5a2e-0f5e-4f5c-9d0a-1e2f3a4b5c6d",
  "cubeID": "my-cube-id",
  "gameType": "burn",
  "players": [
    {
      "playerName": "Alice",
      "draftOrderNumber": 0,
      "cardsDrafted": [],
      "cardsBurned": [],
      "dealtCardPacks": [
        { "packNumber": 0, "cardsInPack": [ /* 6 Cards */ ], "originalCardsInPack": 6, "doubleDraftedFlag": false },
        { "packNumber": 1, "cardsInPack": [ /* 6 Cards */ ], "originalCardsInPack": 6, "doubleDraftedFlag": false }
      ],
      "activeCardPacks": [
        { "packNumber": 0, "cardsInPack": [ /* 6 Cards */ ], "originalCardsInPack": 6, "doubleDraftedFlag": false }
      ],
      "accountID": "acct-1"
    }
  ],
  "gameState": "GAME_STARTED",
  "createdAt": "2026-11-07T04:31:24.779Z",
  "currentPackIndex": 0,
  "draftDirection": "ASCENDING",
  "cardsDraftedPerPack": 1,
  "cardsBurnedPerPack": 1,
  "remainderPolicy": "BURN_EXTRAS"
}
```

Notes:

- `dealtCardPacks` is the full set of packs dealt to the player (one per
  generation); `activeCardPacks` is what they currently hold.
- `currentPackIndex` is 0-based (generation/pack index).
- `draftDirection` is `ASCENDING` for the first generation and flips each time a
  new generation starts.

### 2. Check whether it is your turn

`GET /burn-game/{gameID}/draftCheck`

Headers: `X-Player-Token: <your token>`

**Response `200 OK`**

```json
{ "canDraft": true, "gameState": "GAME_STARTED" }
```

- `canDraft` is `true` only while you hold a pack with cards and the game is
  `GAME_STARTED`.
- Poll this endpoint while waiting; when `canDraft` is `true`, fetch
  [draft data](#3-get-your-draft-state) and submit a [turn](#4-take-a-turn).

| Status | Meaning |
|---|---|
| `401` | token is missing or does not belong to this game |
| `404` | game does not exist |

### 3. Get your draft state

`GET /burn-game/{gameID}/draftData`

Headers: `X-Player-Token: <your token>`

**Response `200 OK`**

```json
{
  "gameID": "8b1f5a2e-0f5e-4f5c-9d0a-1e2f3a4b5c6d",
  "gameState": "GAME_STARTED",
  "draftDirection": "ASCENDING",
  "cardsDraftedPerPack": 1,
  "cardsBurnedPerPack": 1,
  "remainderPolicy": "BURN_EXTRAS",
  "player": {
    "playerName": "Alice",
    "activeCardPacks": [
      { "packNumber": 0, "cardsInPack": [ /* Card... */ ], "originalCardsInPack": 6, "doubleDraftedFlag": false }
    ],
    "cardsDrafted": [ /* Card... */ ],
    "cardsBurned": [ /* Card... */ ],
    "cardsLeftToDraft": 12
  }
}
```

`player.activeCardPacks[0].cardsInPack` is the pack you must act on.
`cardsLeftToDraft` counts cards across all your dealt packs that are neither
drafted nor burned yet.

### 4. Take a turn

`POST /burn-game/{gameID}/draft`

Headers: `X-Player-Token: <your token>`, `Content-Type: application/json`

**Request** — all card IDs must come from the pack in
`player.activeCardPacks[0]`; the two lists must be disjoint and their sizes must
match the rule in [Turn rules](#turn-rules-required-client-logic).

```json
{
  "draftCardIds": ["card-id-1"],
  "burnCardIds": ["card-id-2"]
}
```

**Response `200 OK`** — the cards you drafted this turn (a `Card[]`):

```json
[
  { "name": "...", "cardID": "card-id-1", "details": { /* ... */ }, "cmc": 2, "type_line": "..." }
]
```

The pack remainder is passed to the next player automatically (or discarded if
it became empty). If both players have finished a generation, the next
generation is dealt and the direction flips; if no packs remain the game becomes
`GAME_COMPLETE`.

| Status | Meaning |
|---|---|
| `400` | wrong number of cards, a card not in your pack, the same card drafted and burned, or a malformed body |
| `401` | token missing or not part of this game |
| `404` | game does not exist |
| `409` | the game is not in progress, or you hold no pack |
| `429` | rate limited (see [Errors](#errors)) |

---

### 5. Fetch the full game state

`GET /burn-game/fetchGameData/{gameID}`

**Response `200 OK`** — the same `BurnGameInfo` shape as the creation response.

While a game is in progress this endpoint returns **`409 Conflict`** (use
`draftData`/`draftCheck` for live state). It becomes available once the game is
`GAME_COMPLETE`.

| Status | Meaning |
|---|---|
| `404` | game does not exist |
| `409` | game is still in progress |

---

### 6. End a game

`POST /burn-game/end/{gameID}`

Marks the game `GAME_COMPLETE` (idempotent).

**Response `200 OK`**

```json
{ "gameID": "8b1f5a2e-0f5e-4f5c-9d0a-1e2f3a4b5c6d", "gameState": "GAME_COMPLETE" }
```

| Status | Meaning |
|---|---|
| `404` | game does not exist |

### 7. Per-player game history

`GET /burn-game/history/{playerName}`

`playerName` is URL-encoded (spaces as `%20`). Returns all burn games that
player name appears in, newest first.

**Response `200 OK`**

```json
[
  {
    "gameID": "8b1f5a2e-0f5e-4f5c-9d0a-1e2f3a4b5c6d",
    "cubeID": "my-cube-id",
    "gameState": "GAME_COMPLETE",
    "playerName": "Alice",
    "draftOrderNumber": 0,
    "cardsDraftedCount": 6,
    "cardsBurnedCount": 6,
    "totalPacks": 2,
    "currentPackIndex": 2,
    "createdAt": "2026-11-07T04:31:24.779Z"
  }
]
```

For authenticated users, `GET /account/game/history` (JWT) aggregates burn
games with the other draft types under `gameType: "burn"`.

## Turn rules (required client logic)

For the pack you hold, let:

- `R` = `cardsInPack.length` (from `draftData`)
- `N` = `cardsDraftedPerPack`
- `M` = `cardsBurnedPerPack`
- `policy` = `remainderPolicy` (`BURN_EXTRAS` / `DRAFT_EXTRAS`)

```
if (R >= N + M) {
    draft N cards, burn M cards
} else {
    draft min(N, R) cards
    extras = R - drafted
    if (policy == DRAFT_EXTRAS) draft the `extras` cards too (burn 0)
    else                        burn the `extras` cards
}
```

That is:

- **Full pass**: always draft `N` and burn `M`.
- **Short of the draft quota** (`R ≤ N`): draft everything, burn nothing.
- **Partial pass** (`N < R < N+M`): draft `N`, then either burn or draft the
  leftovers according to `remainderPolicy`.

JavaScript helper:

```js
function planTurn(remaining, draftQuota, burnQuota, policy) {
  if (remaining >= draftQuota + burnQuota) {
    return { draft: draftQuota, burn: burnQuota };
  }
  const draft = Math.min(draftQuota, remaining);
  const extras = remaining - draft;
  return policy === "DRAFT_EXTRAS"
    ? { draft: draft + extras, burn: 0 }
    : { draft, burn: extras };
}
```

Pick any cards from `cardsInPack` in those quantities — the server does not care
about the order of the lists, only the counts and that the IDs are in the pack.

## Errors

- **`400 Bad Request`** — creation payload invalid, cube too small, or an invalid
  turn (wrong counts, unknown card, same card drafted and burned).
- **`401 Unauthorized`** — missing/unknown `X-Player-Token` on `draftCheck`,
  `draftData` or `draft`.
- **`404 Not Found`** — unknown `gameID`.
- **`409 Conflict`** — turn taken while the game is not `GAME_STARTED`, no active
  pack held, or `fetchGameData` while the game is still in progress.
- **`429 Too Many Requests`** — per-client-IP rate limit on `/burn-game`
  (default 120 requests/minute). The response carries `Retry-After` (seconds).
- **`500 Internal Server Error`** — unexpected failures such as the upstream cube
  download failing.

## Lobby integration

You can start a burn draft through the existing lobby flow instead of creating
the game directly. All players keep their lobby tokens as game tokens.

```jsonc
// POST /lobby
{
  "draftType": "burn",
  "config": {
    "cubeID": "my-cube-id",
    "packsPerPlayer": 2,
    "cardsPerPack": 6,
    "cardsDraftedPerPack": 1,
    "cardsBurnedPerPack": 1,
    "remainderPolicy": "burn_extras"
  },
  "hostAccountID": "acct-1",
  "hostDisplayName": "Alice",
  "minPlayers": 2,
  "maxPlayers": 12
}
```

- Create returns `{ "lobby": {...}, "playerToken": "..." }` — keep the token.
- `POST /lobby/{lobbyCode}/join` with `{ "displayName": "..." }` returns the same
  shape for each joiner.
- `GET /lobby/{lobbyCode}` with header `X-Player-Token` polls (heartbeat).
- `POST /lobby/{lobbyCode}/start` with the host token starts the game; the
  response lobby has `status: "STARTED"` and a `gameID`.
- `numberOfPacks` is derived from `players × packsPerPlayer`, so the lobby has
  no `numberOfPacks` key.

Defaults when keys are omitted: `packsPerPlayer=3`, `cardsPerPack=15`,
`cardsDraftedPerPack=1`, `cardsBurnedPerPack=1`,
`remainderPolicy=burn_extras`. Player count defaults to 2–12.

## Full walkthrough

```bash
BASE=http://localhost:8080
GAME=$(curl -s -X POST "$BASE/burn-game" -H 'Content-Type: application/json' -d '{
  "cubeID": "my-cube-id",
  "players": [
    {"name":"Alice","accountID":"acct-1","playerToken":"tok-alice"},
    {"name":"Bob","accountID":"acct-2","playerToken":"tok-bob"}
  ],
  "numberOfPacks": 2, "cardsPerPack": 6, "packsPerPlayer": 1,
  "cardsDraftedPerPack": 1, "cardsBurnedPerPack": 1,
  "remainderPolicy": "burn_extras"
}' | jq -r .gameID)

# Whose turn is it?
curl -s "$BASE/burn-game/$GAME/draftCheck" -H 'X-Player-Token: tok-alice'
# => {"canDraft":true,"gameState":"GAME_STARTED"}

# Read the pack
curl -s "$BASE/burn-game/$GAME/draftData" -H 'X-Player-Token: tok-alice'

# Draft one card and burn one card from that pack
curl -s -X POST "$BASE/burn-game/$GAME/draft" \
  -H 'Content-Type: application/json' -H 'X-Player-Token: tok-alice' \
  -d '{"draftCardIds":["<card-a>"],"burnCardIds":["<card-b>"]}'

# Poll until the game completes, then fetch the final state
curl -s "$BASE/burn-game/$GAME/draftCheck" -H 'X-Player-Token: tok-alice'
curl -s "$BASE/burn-game/fetchGameData/$GAME"
```
